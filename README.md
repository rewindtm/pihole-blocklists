# Pi-hole Blocklists

Lista unica di adlist per Pi-hole, raccolte da varie categorie (generali, pubblicità, tracking/telemetria, malware/phishing, altri) in un solo file.

## Utilizzo

1. Apri l'interfaccia admin di Pi-hole.
2. Vai su **Group Management > Adlists**.
3. Copia gli URL contenuti in [`adlists.txt`](adlists.txt) (uno per riga) nel campo di aggiunta, oppure aggiungili uno per uno.
4. Vai su **Tools > Update Gravity** per scaricare e applicare le liste.

## Contenuto

Il file `adlists.txt` contiene gli URL delle liste ancora attive/mantenute al momento della creazione del repo. Alcune liste storiche note per essere offline o non più aggiornate sono state escluse.
